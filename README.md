# workshop-financial-model-ai

Ateliers pratiques pour financiers et coachs : apprendre à écrire des **AI skills** et à utiliser **Claude dans Excel**, sans être développeur.

Matériel pédagogique — Romandee.com. Pas de conseil fiscal ou financier.

## Ateliers

| Dossier | Durée | Objectif |
|---|---|---|
| [`creer-une-skill`](./creer-une-skill) | 15–20 min | Créer sa première skill (note d'écarts budget vs réalisé) avec Create-Skill |
| [`claude-dans-excel`](./claude-dans-excel) | 20–25 min | Utiliser le plugin Claude for Excel : formules, synthèse, détection d'erreur |

## Prérequis

- **creer-une-skill** : Cursor (ou Claude) avec Create-Skill
- **claude-dans-excel** : Excel Microsoft 365 + add-in Claude
- Excel pour ouvrir les fichiers d'exercice
