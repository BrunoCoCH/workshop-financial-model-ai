# workshop-financial-model-ai

Ateliers pratiques pour financiers et coachs : apprendre à écrire des **AI skills** utiles au pilotage (écarts budget, plans, notes COMEX), sans être développeur.

Matériel pédagogique — Romandee.com. Pas de conseil fiscal ou financier.

## Ateliers

| Dossier | Durée | Objectif |
|---|---|---|
| [`budget-variance-note`](./budget-variance-note) | 15–20 min | Créer sa première skill (note d’écarts budget vs réalisé) avec Create-Skill |

## Prérequis

- Cursor (ou Claude) avec la skill **Create-Skill** disponible
- Excel pour ouvrir le fichier d’exercice
